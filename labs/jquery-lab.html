jQuery Guvenlik Labi (jQuery — kasitli eski)

A) $(kullanici_girdisi) — SELECTOR XSS

jQuery $(), "<" ile baslayan string'i HTML sanar ve element YARATIR. Cogu gelistirici $(x)'in sadece "sectigini" saniyor — ama x HTML ise olusturur. Ornek: $(location.hash).

B) .html(kullanici_girdisi) — innerHTML tarzi SINK

.html() = innerHTML. Ham HTML basar. .text() guvenli olurdu.

C) $.extend(true, {}, JSON) — PROTOTYPE POLLUTION (CVE-2019-11358)

jQuery < 3.4.0'in derin merge'i __proto__ anahtarini engellemez. Az once ogrendigin prototype pollution — burada gercek bir kutuphanede.
